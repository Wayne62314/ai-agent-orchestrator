# Windows 11 黄金旅程实机验收

## 本轮结论边界

这个候选包已经经过自动测试、Windows 安装与卸载冒烟测试、Microsoft Defender
扫描和旧版本升级测试。上述证据不能替代你的实际使用结论。

本轮先恢复 Windows 11 门禁。只有你在真实 Windows 11 设备上完成本页流程，
并且验收记录全部为 `passed`，才可以说 Windows 11 候选版通过。Windows 10
22H2 仍然延期到 Windows 11 通过之后。

## 开始

1. 解压整个候选包，不要只复制安装程序。
2. 双击 `START-WINDOWS11-ACCEPTANCE.cmd`。
3. 脚本会先核对安装包文件名、完整 Git 提交和 SHA-256，然后启动安装程序。
4. 按屏幕提示操作。每项可选择：
   - `P`：亲自观察到通过；
   - `F`：失败，随后填写可复现现象；
   - `B`：受阻，随后填写原因；
   - `N`：暂时不测，稍后再次运行脚本继续。
5. 记录会持续保存在同一目录的 `windows11-acceptance.json`。

不要在备注中填写邮箱、令牌、API Key 或任何认证输出。

## 必须走通的产品路径

安装 → 首次启动且无额外黑框 → Codex 登录 → 账户信息真实 →
新任务无演示填充 → 选择并更换真实仓库 → 无项目命令创建任务 →
Codex 完成一个真实小改动 → 查看分层验收证据 → 200% 缩放 →
纯键盘主要流程 → 本地通知 → 卸载并确认数据保留说明。

## 如何反馈

完成后把 `windows11-acceptance.json` 发回当前 Codex 任务。失败或受阻并不代表记录
无效；准确记录问题比勉强标记通过更重要。只有所有项目都真实通过时，脚本才会显示
“Windows 11 黄金旅程已全部通过”。

项目维护者可以额外运行：

```powershell
python .\stage11_acceptance.py windows11-recovery .\windows11-acceptance.json
```

该命令只是校验证据结构和完整性，不会替代人工观察。
